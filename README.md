# Personal Learning Progress Tracking System
## Description
The Personal Learning Progress Tracking System is a web-based application designed to help students manage their learning activities effectively.
It allows users to create and organize notes, track daily or weekly goals, manage to-do lists and monitor learning progress through an intuitive dashboard.

The system also supports OCR-based note creation, enabling users to upload images and convert them into editable text.

## Features

### Implemented Features
- User authentication (Student & Lecturer roles)
- Student dashboard with progress overview
- Note creation and editing
- To-do list with completion tracking
- Goal setting with progress visualization

### Under Development / Not Yet Functional
- OCR-based note creation (image to text)
- Lecturer material upload features
